# 동행 시간 UTC 전환 적용 사항

신규 모집과 일정 확정·수정 시각은 UTC로 저장하고, 응답은 약속 장소의 도시 시간으로 변환한다. 지원 도시를 찾지 못하면 UTC를 사용한다.

출시 전 데이터는 별도로 변환하거나 보정하지 않는다. 기존 값도 조회 시 UTC로 해석하므로 과거에 현지 시간으로 저장된 테스트 일정은 실제 의도와 다르게 표시될 수 있다.

## 앱 연동 확인

- 앱이 입력 시각을 약속 장소의 현지 시각으로 전송하는지 확인한다.
- 앱이 응답을 기기 시간대로 다시 변환하지 않고 약속 장소의 시간으로 표시하는지 확인한다.
- 서머타임 전환으로 존재하지 않거나 중복되는 현지 시각을 서버가 거부할 때 앱의 처리 방식을 확인한다.
