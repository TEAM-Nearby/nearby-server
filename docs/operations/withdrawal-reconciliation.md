# 회원 탈퇴 연동 해제 조정

탈퇴 시작 시 `user_account.status`는 `WITHDRAWING`이 됩니다. 공급자별 결과는 `withdrawal_progress`에 저장됩니다. `PENDING` 단계와 모든 연동 해제가 `SUCCEEDED`인 탈퇴는 서버가 주기적으로 재개합니다.

`IN_FLIGHT` 또는 `UNKNOWN` 단계는 공급자 요청의 결과가 불분명하므로 자동 재호출하지 않습니다. 운영자는 공급자 측 계정 연동 상태를 확인한 뒤 해당 행을 조정해야 합니다.

- 연동 해제가 완료된 것으로 확인되면 해당 공급자 행을 `SUCCEEDED`로 변경합니다.
- 연동 해제가 이뤄지지 않은 것으로 확인되면 해당 공급자 행을 `PENDING`으로 변경합니다.
- 결과를 확인할 수 없으면 상태를 유지하고 조사합니다. 무조건 `PENDING`으로 되돌리지 않습니다.

조정 후 다음 스케줄 실행이 남은 단계 또는 개인정보 정리를 처리합니다. `WITHDRAWING` 계정의 일반 API와 로그인은 차단됩니다. 암호화 키를 바꾸려면 저장된 Apple Refresh Token을 새 키로 다시 암호화한 뒤 배포해야 합니다.
